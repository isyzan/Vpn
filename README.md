# 🚀 ISYZAN VPN — обход белых списков

**ISYZAN VPN** — это автоматически обновляемый список рабочих серверов для обхода блокировок и белых списков.

---

## 🔥 Особенности

- ✅ 100+ рабочих серверов
- ✅ Автообновление каждые 2 часа
- ✅ Проверка серверов на жизнь
- ✅ Для Incy, Happ, и других клиентов
- ✅ Поддержка: @isyzan

---

## 📥 Как использовать

1. Скачай файл `isyzan_vpn.txt` из репозитория (или из Artifacts в Actions).
2. Импортируй в свой клиент (Incy, Happ, NekoBox и др.).
3. Подключайся и пользуйся.

---

## 🔄 Автообновление

Файл обновляется автоматически каждые 2 часа. Ты можешь скачивать свежую версию в любое время.
